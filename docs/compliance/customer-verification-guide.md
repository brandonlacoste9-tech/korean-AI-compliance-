# 고객 준법 검증 가이드 (Customer Compliance Verification Guide)

**AI 준법 가디언 고객을 위한 한국 AI 기본법 준수 확인 절차**

본 문서는 AI 준법 가디언 서비스를 이용하는 고객이 자사의 AI 시스템이 2026년 1월 22일 시행되는 한국 AI 기본법을 준수하는지 확인하는 단계별 가이드입니다.

---

## 📋 검증 개요

### 검증 목적
- MSIT (과학기술정보통신부) 및 PIPC (개인정보보호위원회) 감사 대비
- 사내 준법 현황 파악
- 준법 증빙 자료 확보

### 소요 시간
- **기본 검증:** 약 30분
- **심화 검증 (MSIT 제출용):** 약 2시간

### 준비물
- AI 준법 가디언 계정 (Professional 플랜 이상 권장)
- 자사 AI 시스템 현황 파악 자료
- 개인정보 처리 내역

---

## ✅ Step 1: 서비스 접속 및 위험 평가 실행

### 1.1 로그인
1. https://korean-ai-compliance.vercel.app 접속
2. 계정 정보로 로그인
3. 대시보드 확인

### 1.2 AI 위험 평가 수행
1. "위험 평가 시작" 버튼 클릭
2. 다음 정보 입력:
   - **회사명:** 귀사의 정식 회사명
   - **이메일:** 담당자 이메일
   - **AI 사용 분야:** 귀사 AI 시스템이 사용되는 산업/분야
     - 예: "의료", "금융", "제조", "마케팅"
   - **개인정보 처리 여부:** 예/아니오
   - **안전 영향 여부:** AI 결정이 생명/재산에 영향을 미치는지 여부

3. "평가 시작" 클릭
4. 결과 확인:
   - **위험도 점수** (0-100)
   - **위험 등급:** 고위험 / 중위험 / 저위험
   - **권장 플랜:** Professional / Starter
   - **필요 조치 사항**

### 1.3 결과 저장
- 평가 결과 PDF 다운로드 (Professional 플랜)
- 스크린샷 저장 (모든 플랜)

**✅ 체크포인트:** 위험 평가 완료 및 결과 확인

---

## ✅ Step 2: 동의 로그 확인

### 2.1 동의 기록 조회
1. 대시보드에서 "동의 로그" 메뉴 선택
2. 필터 옵션 설정:
   - **기간:** 최근 3개월 (PIPC 감사 표준 기간)
   - **동의 유형:** 전체 또는 특정 유형
   - **동의 여부:** 동의함 / 거부함

3. 조회 결과 확인:
   - 총 동의 건수
   - 동의율 (%)
   - 최근 동의 일시

### 2.2 필수 확인 사항
다음 정보가 모든 동의 로그에 기록되었는지 확인:
- ✅ 사용자 식별자 (이메일 또는 ID)
- ✅ IP 주소
- ✅ 타임스탬프 (KST)
- ✅ 동의 텍스트 (한국어 + 영어)
- ✅ 동의 방법 (체크박스, 버튼 클릭 등)

**⚠️ 주의:** 동의 로그가 없으면 PIPC 위반으로 간주될 수 있습니다.

**✅ 체크포인트:** 동의 로그 존재 및 필수 정보 포함 확인

---

## ✅ Step 3: 감사 로그 검토

### 3.1 감사 로그 조회
1. "감사 로그" 메뉴 선택
2. 다음 로그 유형별로 확인:
   - **데이터 접근:** 누가, 언제, 어떤 데이터에 접근했는지
   - **AI 처리:** AI 모델이 언제 어떤 결정을 내렸는지
   - **보안 이벤트:** 로그인 실패, 권한 변경 등

### 3.2 감사 로그 요구사항 확인
각 로그에 다음 정보가 포함되어 있는지 확인:
- ✅ 작업 (Action)
- ✅ 작업자 (Actor)
- ✅ 리소스 유형 및 ID
- ✅ IP 주소
- ✅ 목적 (Purpose)
- ✅ 결과 (성공/실패)
- ✅ 타임스탬프 (KST)

### 3.3 보관 기간 확인
- **최소 보관 기간:** 3년 (PIPC 요구사항)
- AI 준법 가디언은 자동으로 3년간 보관

**✅ 체크포인트:** 감사 로그 정상 기록 및 보관 확인

---

## ✅ Step 4: CSV 내보내기 (MSIT/PIPC 제출용)

### 4.1 감사 자료 내보내기
1. "내보내기" 메뉴 선택
2. 내보내기 옵션 설정:
   - **로그 유형:** 동의 로그 / 감사 로그 / AI 처리 로그
   - **기간:** 감사 기간 (예: 최근 1년)
   - **포맷:** CSV (한국어 헤더 포함)

3. "내보내기" 버튼 클릭
4. CSV 파일 다운로드

### 4.2 내보낸 파일 확인
- 파일명: `audit_logs_export_YYYYMMDD_HHMMSS.csv`
- 인코딩: UTF-8 (Excel 호환)
- 헤더: 한국어 + 영어 병기

### 4.3 MSIT/PIPC 제출 준비
다음 파일을 준비:
1. `consent_logs_export.csv` - 동의 기록
2. `audit_logs_export.csv` - 감사 로그
3. `ai_processing_logs_export.csv` - AI 처리 이력
4. `risk_assessment_report.pdf` - 위험 평가 보고서

**✅ 체크포인트:** CSV 파일 정상 다운로드 및 내용 확인

---

## ✅ Step 5: 투명성 확인

### 5.1 AI 투명성 요구사항
다음 사항이 충족되는지 확인:
1. **AI 사용 고지:**
   - 웹사이트 또는 앱에 "이 서비스는 AI를 사용합니다" 문구 표시
   - 한국어: "이 결과는 AI가 생성했습니다"
   - 영어: "This result is generated by AI"

2. **설명 메커니즘:**
   - AI 결정에 대한 간단한 설명 제공
   - 주요 영향 요인 표시 (예: "귀사는 의료 분야이므로 고위험으로 분류됩니다")

3. **사람 개입 옵션:**
   - "사람 검토 요청" 버튼 또는 연락처 제공
   - 이의 제기 프로세스 명시

### 5.2 AI 준법 가디언 투명성 기능 활용
- 대시보드에서 "투명성 체크리스트" 확인
- 자동 생성된 AI 사용 고지 텍스트 사용
- 준법 배지 웹사이트에 표시

**✅ 체크포인트:** 투명성 요구사항 충족 확인

---

## ✅ Step 6: 보안 조치 확인

### 6.1 필수 보안 조치
다음 보안 조치가 적용되었는지 확인:
- ✅ **암호화:** 개인정보 AES-256 암호화
- ✅ **전송 보안:** TLS 1.3 사용
- ✅ **접근 통제:** 역할 기반 접근 제어 (RBAC)
- ✅ **백업:** 일일 자동 백업
- ✅ **모니터링:** 실시간 보안 이벤트 감지

### 6.2 AI 준법 가디언 보안 현황
- 대시보드 > "보안 상태" 메뉴에서 확인
- 보안 점검표 다운로드

### 6.3 인증 현황
- **ISMS-P** 또는 **ISO 27001** 인증 진행 상황 확인
- 인증 계획 수립 (고위험 시스템 필수)

**✅ 체크포인트:** 보안 조치 적용 확인

---

## ✅ Step 7: 국내 대리인 확인 (해외 사업자)

### 7.1 대리인 지정 여부
귀사가 해외 법인인 경우:
- **국내 대리인 지정 필수** (AI 기본법 제36조)
- 대리인 정보:
  - 이름 (개인 또는 법인)
  - 한국 내 주소
  - 연락처 (전화, 이메일)

### 7.2 대리인 등록
1. MSIT 포털 (https://www.msit.go.kr) 접속
2. "AI 기본법 대리인 등록" 메뉴
3. 대리인 정보 입력 및 제출
4. 등록 확인증 수령

**✅ 체크포인트:** 대리인 지정 및 등록 완료 (해외 사업자)

---

## ✅ Step 8: 종합 준법 점수 확인

### 8.1 준법 점수 조회
1. 대시보드에서 "준법 점수" 확인
2. 점수 산정 기준:
   - 위험 평가 완료: 15점
   - 동의 로그 정상: 20점
   - 감사 로그 정상: 20점
   - 투명성 조치: 15점
   - 보안 조치: 15점
   - 문서화: 10점
   - 대리인 지정 (해외): 5점
   - **만점: 100점**

### 8.2 점수 해석
- **90-100점:** ✅ 완전 준수 (Full Compliance)
- **70-89점:** ⚠️ 대부분 준수 (Mostly Compliant)
- **50-69점:** ⚠️ 부분 준수 (Partially Compliant)
- **0-49점:** 🚨 높은 위험 (High Risk)

### 8.3 개선 권고사항
- 점수가 90점 미만인 경우 "개선 항목" 탭 확인
- 우선순위별 조치 계획 수립

**✅ 체크포인트:** 준법 점수 90점 이상 달성 목표

   - 이메일: support@aicomplianceguardian.kr

### 데이터 누락 발견 시
1. 즉시 회사에 문의 (support@aicomplianceguardian.kr)

- **월 1회:** 동의 로그 및 감사 로그 확인
- **분기 1회:** 종합 준법 점수 점검
- **연 1회:** 전체 시스템 감사 및 MSIT 제출용 자료 준비

- 준법 점검 알림 (월간)
- 법령 변경 알림 (실시간)
- 제출 기한 알림 (분기별)
