## ✅ Step 1: Determine Applicability

**확인 사항 (Check if):**

- [ ] **Does your AI system serve Korean users or markets?**
  - 귀사의 AI 시스템이 한국 사용자나 시장을 대상으로 합니까?

- [ ] **Is your system used in critical domains?**
  - Healthcare (의료)
  - Finance (금융)
  - Education (교육)
  - Security (보안)
  
- [ ] **Does your system involve:**
  - Automated decision-making (자동화된 의사결정)
  - Recommendations (추천 시스템)
  - Generative AI (생성형 AI)

> **⚠️ If YES to any:** You are subject to Korean AI Basic Act.

## ✅ Step 2: Conduct Risk Classification

**위험도 분류 (Risk Assessment):**

### High-Impact AI Systems (고위험 AI):
- Medical diagnosis systems
- Credit/loan decision systems
- Autonomous vehicles
- Facial recognition (public spaces)
- Hiring/employment decision systems

### General Use AI Systems (일반 AI):
- Chatbots
- Content recommendations
- Non-critical analytics
- Internal productivity tools

### Action Items:
- [ ] **Classify your system** as High-Impact or General Use
- [ ] **Document evaluation method** (impact scoring matrix)
- [ ] **Store classification logs** for audit trail

## ✅ Step 3: Ensure Transparency

**투명성 보장 (Transparency Requirements):**

- [ ] **Clearly disclose AI usage to users**
  ```
  Example: "이 결과는 AI가 생성했습니다"
  Example: "This result is generated by AI"
  ```

- [ ] **Provide explanation mechanisms** for high-risk decisions
  - Show reasoning process
  - Explain key factors
  - Offer alternative options

- [ ] **Include disclaimers or human-in-the-loop options**
  - "Request human review" button
  - Contact for appeal process
  - Clear escalation path

**Penalty:** ₩30M fine for non-disclosure

---

## ✅ Step 4: Appoint Local Representative

**국내 대리인 지정 (Local Representative):**

### If you have NO local Korean presence:

- [ ] **Designate a Korean legal representative**
  - Must be individual or legal entity in Korea
  - Must have authority to respond to MSIT/PIPC
  - Must respond within mandated deadlines

- [ ] **Submit representative information to:**
  - MSIT Portal: https://www.msit.go.kr
  - PIPC Portal: https://www.pipc.go.kr

- [ ] **Ensure representative can:**
  - Receive compliance inquiries
  - Respond to audit requests
  - Represent company in legal matters

**Penalty:** ₩30M fine for no representative


## ✅ Step 5: PIPC-Compliant Audit Logging

**감사 로깅 (Audit Log Requirements):**

### Required Logs:

- [ ] **Consent Logs**
  ```
  Fields to store:
  - User ID
  - Timestamp (KST timezone)
  - Consent type
  - IP address
  - Consent text shown
  - User acceptance method
  ```

- [ ] **Data Access Logs**
  ```
  Fields to store:
  - Who accessed (user/system)
  - What data (type, record IDs)
  - When (timestamp in KST)
  - Why (purpose)
  - Result (success/failure)
  ```

- [ ] **AI Processing History**
  ```
  Fields to store:
  - Input data (or hash)
  - AI model version
  - Processing timestamp
  - Output/decision
  - Confidence score
  - Human override (if any)
  ```

- [ ] **Enable audit log download/export**
  - CSV format for MSIT/PIPC
  - Retention: Minimum 3 years
  - Encryption: At rest and in transit

## ✅ Step 6: Security & Safety Requirements

**보안 및 안전 (Security Protocols):**

- [ ] **Implement ISMS-P or ISO 27001 security**
  - Information Security Management System - Personal Information (ISMS-P)
  - Certified by KISA (Korea Internet & Security Agency)
  - ISO 27001 accepted as alternative

- [ ] **Set up real-time monitoring**
  - AI model drift detection
  - Anomaly detection
  - Performance degradation alerts
  - Security incident alerts

- [ ] **Provide human fallback and override**
  - Emergency stop mechanism
  - Human review process
  - Override authorization workflow
  - Incident response team

### Security Checklist:

```
[ ] Encrypted data storage (AES-256)
[ ] Encrypted data transmission (TLS 1.3)
[ ] Access control (role-based)
[ ] Multi-factor authentication
[ ] Regular security audits (quarterly)
[ ] Penetration testing (annual)
[ ] Incident response plan
[ ] Data breach notification procedure
```
