# Korea AI Compliance Scanner

## "TurboTax for Korean AI Compliance"

**Target:** Technical founders who shipped AI and just realized they're in violation.

---

## Product Vision

- Self-serve (no sales cycle)
- Credit card signup
- 20-minute setup flow
- Transparent pricing ($99-499/month)

---

## MVP Features

### Week 1-2: Classification Engine

**Input:** Product description / API endpoints / model names

**Output:**
1. Risk classification (High-Impact / Generative / Low-Risk)
2. Checklist of required compliance items
3. Korean-language notification templates

### Week 3-4: CI/CD Integration

- GitHub Action / pre-commit hook
- Scans for AI triggers
- Flags compliance gaps

---

## Tiered Pricing

| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | One-time classification check |
| **Builder** | $99/mo | Unlimited checks, templates, GitHub integration |
| **Enterprise** | $499/mo | API access, domestic representative, audit support |

---

## Tech Stack

- **Frontend:** Next.js (from korean-AI-compliance- frontend)
- **Backend:** FastAPI (existing)
- **AI:** browser-use + OpenAI for classification
- **Storage:** Supabase Seoul
- **Payments:** Stripe KRW
